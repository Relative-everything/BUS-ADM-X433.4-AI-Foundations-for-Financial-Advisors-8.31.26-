# CASE.md, the Cole household

Canonical source of truth for the course case, ratified 2026-08-18.

The Cole household is **entirely synthetic**. It was constructed for this
course. It is not derived from, based on, or de-identified from any real
household, and it is not the dataset for the final project. Every lesson that
presents it says so on the page.

## How this file governs the lessons

Session 1 introduces the case and carries the full block below verbatim.
Sessions 2 through 4 carry shorter recall summaries rather than the full block,
because they revisit the case rather than introduce it. **Every figure in those
summaries must match this file.** Changing a figure means changing this file
and every lesson that states it, in the same commit.

Retired case names are listed in MAINTAINING.md under the standing purge list.

## Documents in the case file

2011 wills pouring over to a joint revocable trust; 2014 buy-sell using a stale
formula value that conflicts with the $18,000,000 appraisal; 2023 appraisal;
2011 powers of attorney and directives; unexecuted draft IDGT and note; no
irrevocable life insurance trust.

## The question that stays open

Is the planning window still open now that a buyer has expressed interest, and
does a 2023 appraisal still support a 31% discount today?

No session answers it. Every session returns to it. This is the deliberately
unresolved technical question the case is built around.
