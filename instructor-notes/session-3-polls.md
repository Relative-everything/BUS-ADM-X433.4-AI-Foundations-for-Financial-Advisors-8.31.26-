# Session 3 Zoom polls: six to choose from, four recommended

Written 2026-09-18. Build them in the Zoom web portal before Monday; a poll configured live was
retracted in Session 2. Every block below is laid out the way Zoom's poll editor asks for it:
title, question, one option per line, single choice unless marked. Copy a block, paste each line
into its field. Set **Anonymous** only where marked.

**Recommended set: 1, 2, 3, 4.** These are the four the run sheet and the teaching aid fire, each
with a written decision rule. 5 and 6 are optional: 5 is the pace check the Session 2 audit asked
for (two spoken pace check-ins returned silence), 6 replaces the spoken vote on §09 item 1 with an
anonymous split. Do not run more than five; each costs about a minute.

Every poll below is single choice. Read the result aloud, then take the branch or decline it
aloud; declining aloud still counts.

## Poll 3 · 7:34 · recommended

```
Title: The appraisal

(a) The appraisal is out of date
(b) The appraisal shares almost no words with the question
```

(a), re-run preset 1 and read the shared-term line aloud before moving on.
