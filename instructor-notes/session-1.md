## The named discussion (s14c, minutes 41 to 56): predicted split

**The question.** You used a frontier model to summarise the Cole discovery meeting; the summary was accurate and you reviewed it line by line before it went in the file. Does Meg have to be told? A: disclose proactively, in the engagement letter and again when AI materially shapes a deliverable. B: only if asked; answer honestly and completely, do not volunteer. C: no; it is an internal tool like a calculator and the work product is yours either way.

**Predicted split (a prediction, not data).** No Fall 2026 room ran this discussion: all six sat in the appendix and none ran in Session 1 or 2. For N about 8: first vote A 3, B 4, C 1 (about 35, 50 and 15 percent); second vote A 4, B 3, C 1. Reasoning: B is the position that sounds most professional and costs least to hold, so it draws the plurality; C is the position fewest people will defend aloud; A draws anyone who thinks about what is on the record if the file is questioned. The complication below is built to cut both ways, so expect a small delta. After the first run, replace this paragraph with the real split.

**Mechanics (PEDAGOGY 9.5), 15 minutes.**
- Position, 3 min: Poll 4a, not anonymous, everyone commits before anyone speaks. Locked. Students also seal their own vote on the page.
- Defence, 9 min: the minority argues first, then alternating, 90 seconds each, called by name. Use the defences on the page. After about six minutes, read the complication.
- Re-vote, 3 min: Poll 4b, the same question. Show both distributions side by side and say nothing about the delta. A zero delta is a finding: a defensible position held under argument.
- If one option holds 6 or more of 8 in vote 1, the room will not divide; follow the decision rule in the polls file.

## Close (s15, minutes 56 to 60)

Read the pull line: it predicts, it does not know. Then the two-minute written check, then "Compare with the key". The prompt: a model has handed you a clean, confident, well-written answer about how much the Coles should convert to Roth; name the one thing this session said you still cannot conclude, and say which part of the machine is the reason. The key has both halves: you cannot conclude that the number is right or that a second run gives the same one; the reason is the sampler, which drew a likely continuation and checked nothing; and for the Roth question there is nothing to look up, because the case leaves the judgment open. Handoff in one breath: Session 2 is the first session in which you change the output, because prompt construction is the only control that operates before the sampler runs. The reading card for Session 2 at the foot of the page is generated; do not edit it by hand.
