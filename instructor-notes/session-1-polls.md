# Session 1 polls

Four polls, built in Zoom before class; students are not co-hosts. Questions under 255 characters, answers under 100. N is about 8: "a third" is 3, "half" is 4. The case opener's commit is a chat waterfall (type A, B or C on "go"), not a poll. If a poll fails to launch, run it as a chat waterfall. Session 1 has no retrieval bridge.

## Poll 1
- **Fires:** s2, opens it. **Format:** numeric-range prediction.
- **Question:** Wolfram names one temperature setting that "seems best" for essays. Temperature 0 always takes the top-ranked word. Where does the best setting sit?
- **Options:** A Exactly 0 / B Above 0 up to 0.5 / C Above 0.5 up to 1.0 / D Above 1.0
- **Expected:** C (0.8). Wolfram (2023), "It's Just Adding One Word at a Time", quoted on s2; confidence H.
- **Decision rule:** If 3 or more pick A, run T = 0 first and read "Longest repeat" aloud before T = 0.8, and plant one line for s9: repeatable is not correct. Otherwise reveal and take the panels in page order.
- **Zoom:** single choice, anonymous, 4 answers.

## Poll 2
- **Fires:** s9, closes it, before "The planning version". **Format:** single choice with a surprising, checkable answer.
- **Question:** Meg Cole was born 2 May 1968. At what age must she take her first required minimum distribution?
- **Options:** A 70 and a half / B 72 / C 73 / D 75
- **Expected:** D, 75. CASE.md Parts C.3.1 and F.4 (IRC 401(a)(9)(C)(v) as amended by SECURE 2.0 section 107; T.D. 10001); confidence M. Each other option was the age under an earlier version of the rule.
- **Decision rule:** If fewer than half pick D, spend 60 seconds on the version history and ask which version a model has seen most: the room just did what the model does. Otherwise say the room is right, skip the history and go to the Roth question, which has no answer to retrieve.
- **Zoom:** single choice, anonymous, 4 answers.

## Poll 3
- **Fires:** s14b, opens it; hold the result for Step 3. **Format:** multi-select.
- **Question:** Select every line you would put in a standing instruction that attaches to every future conversation on your account.
- **Options:** A Credential and role / B Standing verification requirement / C Confidence labels (H, M, L) with sources / D Answer first, then reasoning / E Push back on a flawed premise / F Keep disagreement separate when summarising / G My clients' goals and balances, so I never paste them again
- **Expected:** A and B belong (s14b, "What actually belongs in there"); G never does (s13 Course rule). C to F are style choices with no key.
- **Decision rule:** Click the top three counts into Step 3. If B is not among them, add it and say why. Always add the no-client-detail element. If G drew any ticks, take 30 seconds: a standing instruction rides along on every chat.
- **Zoom:** multiple choice, anonymous, 7 answers.

## Poll 4
- **Fires:** s14c, opens it; repeat the identical poll as the re-vote. **Format:** single choice (the second).
- **Question:** You used a frontier model to summarise the Cole discovery meeting and checked it line by line before it went in the file. Does Meg have to be told?
- **Options:** A Yes: disclose it up front, in the engagement letter and on deliverables it shapes / B Only if asked: answer fully and honestly, do not volunteer it / C No: it is an internal tool like a calculator; the work is mine either way
- **Expected:** No key; vote 2 against vote 1 is the result. Notice 24-09 does not require disclosure (FACTS:finra-24-09-status; s14c; A10). Predicted, of 8: vote 1 A 3, B 4, C 1; vote 2 A 4, B 3, C 1 (a prediction, see session-1.md).
- **Decision rule:** If no option holds half, run the protocol, minority first. If one holds 6 or more of 8, assign the two nearest the middle to argue the emptiest position. After vote 2 show both bars and say nothing about the delta; a zero delta is a finding.
- **Zoom:** single choice, not anonymous (call the minority by name), 3 answers; name them "4a first vote" and "4b second vote"; share results after 4b.
