# Zoom poll setup (built ahead of class)

Build every poll before the session starts; Zoom's in-meeting poll editor is where Fall 2026 lost two polls to setup.

1. **Where polls live.** Zoom web portal, Meetings, the scheduled meeting, the Polls/Quizzes tab, Create. Build there, not in the client during class. Advanced polls are off by default: enable them first under Settings, In Meeting (Basic), Meeting Polls/Quizzes, "allow hosts to create advanced polls and quizzes". The host must be a Licensed user; a meeting holds at most 50 polls. (Verified 2026-10-12 against four university Zoom help pages, M; menus move between Zoom versions, so check the portal the week before.)
2. **Single choice with a surprising, checkable answer.** One question, three to five options, one correct. Title it with the section id so the launch list reads in run order ("S4-02 breach clock").
3. **Multi-select.** Basic and advanced polls both offer Multiple Choice; set it to allow more than one answer (the help pages call the single-answer form "single choice" and the multi-answer form "multiple choice"). Put the number of correct answers in the question ("pick two").
4. **Numeric-range prediction.** There is no numeric type: use single choice with five range buckets, the correct bucket not in the middle, and name the exact figure in the reveal.
5. **Short answer or ranking.** Advanced polls add Matching, Rank Order, Short Answer and Long Answer. Use Short Answer with a tight character limit, or Rank Order. These two were the ones that broke in Fall 2026 when a student was made co-host mid-poll.
6. **Do not make students co-hosts during a poll.** Co-host status reassigns poll control and ended the Session 5 short-answer poll. Promote a student only after results are shared and the poll is closed.
7. **Launch and share.** Polls, pick the title, Launch; watch the response count, not the clock; End Poll, then Share Results so the distribution is on screen before anyone speaks (PEDAGOGY 9.5: everyone commits before anyone speaks).
8. **Record the distribution.** Type the counts into the chat as a line ("A 3, B 4, C 1") so the re-vote can show both distributions.
9. **30-second fallback when a poll fails.** Say "chat waterfall": everyone types their answer in chat but does not press Enter; on "go" everyone sends at once. Read the distribution aloud, then continue with the decision rule as if the poll had run.
10. **After class.** Download the poll report from the meeting's Reports page the same day; the distributions feed next term's predicted splits.

Sources (M): the Zoom help pages republished by Northern Illinois, Quinnipiac, Colorado Mesa, UCL and Utah State (university Zoom guides found 2026-10-12); Zoom's own support site was not fetched.
