The Task a Transformer Cannot Reliably Learn

Wolfram trains a small transformer on a language with exactly one rule: parentheses must balance. It learns it well enough to look right, then fails.

From the assigned reading — his figures, section "What Really Lets ChatGPT Work?"With 2 attention heads the learning converges after "10 million or so examples." Yet with its "400,000 or so laboriously trained weights," it still assigns a 15% probability to a closing parenthesis that would leave the sequence unbalanced. And: "even the full current ChatGPT has a hard time correctly matching parentheses in long sequences."
Sequence builder — the simulated model predicts what comes next
depth 0

Simulated shallow model — confidence degrades with depth, as Wolfram's trained net does

Counting is algorithmic. The network is feed-forward — "there's no looping or 'going back'" — so it approximates a counter from local pattern, and the approximation decays with depth.

Anything requiring an exact count across a long document is the failure case, not the edge case.

Where this bites in the Cole file — discussionEvery one of these is a counting or reconciliation task inside a long sequence, and every one is a place a fluent answer is least trustworthy:
  • Confirming the 2024 Roth conversion memo against the January 2026 plan summary, and listing every provision that conflicts
  • Checking that the $210,000 rollover IRA balance is the same figure on the statement, the beneficiary form summary and the balance sheet
  • Verifying that the 16.8% concentration is computed on the taxable account ($60,500 of $360,000), not on investable assets (2% of $2,446,000), in each place it appears
  • Tracing whether the 2011 powers of attorney were superseded by anything executed since, and confirming the file holds no later restatement

Turn the knobs until the curve fits the fall times. You are minimising a loss function by hand — which is what training does, 175 billion knobs at a time.

Loss—

Try the third form. It has as many knobs as the second and cannot fit this data at any setting, because its structure is wrong. The choice of structure is made before any data arrives, and no amount of training rescues a bad one.

Planning parallel — discussionEvery Monte Carlo engine you run is a model with knobs: return assumptions, inflation, sequence-of-returns treatment, mortality table. A 91% probability of success is not a measurement. It is the output of a structure someone chose, fitted to assumptions someone set.

Confident tone is not a claim about confidence. It is the output of the scoring rule.

This is the first rung of a three-step ladder: why it happens (this session), how often it happens against a real corpus (Session 3), and what it costs you (Session 4).

The planning versionAsk any frontier model at what age a person born in 1968 must start required minimum distributions, and it will give you a number in a confident sentence. That age has one right answer, the model has seen several earlier versions of it in near-identical sentences, and it has no way to signal which one applies. Now ask how much the Coles should convert to Roth. The sentence is just as confident, and there is no answer to retrieve, because that is a judgment the case leaves open.
  • Sort Meg's questions into arbitrary facts, which have one right answer and many plausible wrong ones, and contested judgments, which have none to retrieve. The first list you verify line by line. The second you never delegate at all.

Existing FINRA Rules as Applied to AI

FINRA's rules are technology-neutral. Regulatory Notice 24-09 creates no new obligations — it confirms the existing ones already reach this.

RuleAs applied to AI
Rule 3110 — SupervisionA reasonably designed system addressing technology governance, model risk management, data privacy and integrity, and model reliability and accuracy
Rule 2210 — CommunicationsContent standards apply to AI-generated content identically to human-generated content
Rules 3110.09, 4511; SEA 17a-4AI-generated correspondence must be retained
Third-party vendor useObligations apply whether the tool is built in-house or licensed

On 18 March 2024 the SEC settled against two advisers over AI claims: Delphia (USA) Inc., $225,000, for saying it used client data with machine learning when it had collected the data and never used it that way; and Global Predictions, Inc., $175,000, for advertising "expert AI driven forecasts" without substantiation. Both censured and ordered to cease and desist, under Advisers Act §206(2), §206(4) and Rules 206(4)-1 and 206(4)-7. Neither case was about a wrong answer. Disclosure of AI Use to the Client

You used a frontier model to summarise the Cole discovery meeting. The summary was accurate and you reviewed it line by line before it went in the file. Does Meg have to be told?

First vote — commit before anyone speaks

Complication — read this after you have argued both sidesNothing in FINRA 24-09 requires disclosure of AI use to a client. The Notice says existing rules apply as written. So the question is not what the rule requires. It is what you would want on the record if the summary had been wrong and Meg's counsel asked how the file was produced.
Second vote — same question, after the argument
Cast the second vote.
Room tally — instructor keys in the Zoom poll counts

A zero delta is a finding, not a failure. It means a defensible position held under argument, which is the same epistemic move this course asks you to make about model output.
