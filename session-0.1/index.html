The twelve terms Session 1 uses
Token
A word or word fragment: the unit a model reads and writes.
Next-token prediction
The model's one operation: score every possible next token, given the text so far.
Probability distribution
The list of candidate next tokens, each with a chance attached.
Sampling
The step that picks one token from that list.
Temperature
The setting that decides how often sampling picks below the top-ranked candidate.
Hallucination
A fluent, confident statement that is false.
Model tier
A size and price level within one vendor's models, such as Haiku 5.5 or Opus 5.5.
Context window
All the text the model can reference when it writes a response, the response included. H
Project
A Claude workspace with its own instructions, applied only to the conversations inside it.
Custom instructions
Standing text that shapes every new conversation on your account.
Skill
A saved set of instructions that Claude loads when a task calls for it.
Nonpublic personal information (NPI)
