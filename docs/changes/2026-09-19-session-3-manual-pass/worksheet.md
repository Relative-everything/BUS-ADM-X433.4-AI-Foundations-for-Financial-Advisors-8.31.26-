# Session 3 manual-pass worksheet, 2026-09-19

One block per stop on the night, in the order the teaching aid runs them. For each: what is on
screen, the one click, the one question and its answer, and three things worth your eyes. Write
notes under the id (MP-00 and so on) into `notes-verbatim.md` beside this file, or on paper; the
id is enough for the next pass to find the anchor. Open the page at Core only, the Session 2 page
in a second tab at "+ Standard", and the aid beside you.

A note is most useful when it says which of three things it is: **wording** (say it differently),
**cut** (this should not be here), or **wrong** (this is false for the room). Anything else is a
proposal, and those are welcome too.
