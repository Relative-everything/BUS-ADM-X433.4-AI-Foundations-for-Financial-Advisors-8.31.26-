# Meridian restyle, step 1.3: the page-local variations

Written 2026-11-15. **This is the one planned pause.** Each row is a page-local rule that has the same selector (and the same `@media` condition) as a rule in the shared style fence, with different declarations. A page-local rule comes later in the file, so today it wins on its page. There are 74 distinct rules, 201 instances across the twelve pages.

The table shows only what differs. A page rule adds to the fence rule; it never removes from it, so a declaration the page does not repeat still applies. The full text of every rule is in `variations-answers.json` beside this file.

## The four verdicts

| Verdict | What happens | Count |
|---|---|---|
| **drop** | The page rule is deleted in step 1 and the page takes the shared look. | 50 |
| **keep** | The page rule stays as written. Step 2 converts its values to tokens like any other page-local rule. | 16 |
| **keep additions only** | The declarations the fence does not set stay; the ones that only change a shared value go. | 1 |
| **keep, retire in step 2** | The page's version is the one Meridian's shared rule adopts. It stays through step 1 so nothing moves, and is deleted in step 2 when the shared rule says the same thing. | 7 |

## What dropping changes on screen in step 1

Of the 50 drops, 9 change nothing at all (rows 1, 2, 8, 10, 11, 22, 28, 47, 61: the page rule only repeats the fence). The rest are visible, all on Sessions 2 to 5 and the hub:

- Sessions 2 to 5: type and spacing tighten by 1 to 4 px (h1 at most 62 to 58 px, body leading 1.65 to 1.62, section padding 48/88 to 44/74 px). Rows 13 to 20, 29 to 32, 35 to 37, 41 to 46, 48, 50, 55, 56, 58, 59, 62 to 64, 66 to 70.
- Session 2: its top bar becomes the shared bar. Rows 24 to 26.
- Hub: h3 at most 1 px smaller. Row 5.

Step 2 then replaces every one of those shared values with Meridian's, so the drops decide only whether Sessions 2 to 5 follow the shared scale or keep a private one.
